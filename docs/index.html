🔬 Complete 100% Offline Hardware Architecture

From physical sound waves to synthesized multilingual voice with zero cloud dependency.

01

Audio Preprocessing & 26 MFCC Extraction

16 kHz Mono Audio is split into 25ms windows with 10ms hops. Computes 13 MFCC coefficients (Mean + Standard Deviation = 26 features).

10-Step DSP Pipeline
02

PYNQ-Z2 FPGA Neural Network Accelerator

Memory-mapped AXI4-Lite registers (`0x43C00000`). Synthesizable Verilog MLP executes Q8.8 matrix multiplications in hardware.

0.42 ms Latency
03

Local Speech-to-Text (ASR)

Faster-Whisper (quantized INT8 CTranslate2) generates precise transcripts directly in native English, Hindi, and Tamil scripts.

Offline Whisper
04

Plan-Act-Verify Agent Reasoning

Deterministic local knowledge engine + local Ollama LLM verifies institutional facts with strict bounds before replying.

Deterministic Guardrails
05

Local Text-to-Speech (TTS)

Native Windows SAPI5 (pyttsx3) and Piper local neural voices produce natural synthesized voice audio without internet.

Zero Cloud Overhead

💻 Running Locally

Launch the full Streamlit dashboard or CLI receptionist on Windows or Linux with one command.

git clone https://github.com/jaganbala2007/language-fpga.git
cd language-fpga

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch Voice-First Web Application (Streamlit)
streamlit run app.py
# Opens at http://localhost:8501
